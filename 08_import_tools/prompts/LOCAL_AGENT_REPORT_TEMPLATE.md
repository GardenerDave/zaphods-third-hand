# Local Agent Report Template

Use this structure for local-agent outputs. When the report is written to a markdown file, return raw markdown only and do not wrap the whole report in an enclosing code fence.

```markdown
# Local Agent Report

## Task
- Task ID:
- Model:
- Role:
- Date:

## Summary

## Findings / Draft Output

## Evidence References
- file path and line number when available
- command output path when applicable

## Uncertainty

## Files Inspected

## Personal / Runtime Data Handling
- Personal or runtime data was used: yes / no
- Raw personal details included in this report: yes / no
- Sanitized evidence provided instead:

## Recommended Next Action

## Resource Report
- Input tokens:
- Output tokens:
- Token counts are exact or estimated:
- Elapsed seconds:
- Observed tokens per second:
- Notes:
```
