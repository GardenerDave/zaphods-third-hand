# Behavior Correction Cards

This directory holds explicit, packet-level correction cards used by
supervised ZTH workflows.

Cards are evidence-backed scaffold guidance only. They are not default
behaviors, not weight edits, not adapter training, and not promotion
authority.

Current example cards:

- [`file_scope_hold_out_v1.json`](file_scope_hold_out_v1.json) — hold out
  adjacent and unauthorized files explicitly in file-scope authorization
  packets.
