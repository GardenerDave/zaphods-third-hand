# Affordance Dogfood Report v0

Status: experimental model-free report scaffold

Affordance Dogfood Report v0 reviews one generated LARQL affordance candidate
after a dogfood run. It checks whether the candidate is useful, specific,
provenance-bearing, split-host safe, and still safely unpromoted.

It does not run LARQL, call models, train LoRA, mutate model weights, create
vindexes, create adapters, or promote artifacts.

## Purpose

The report gives an operator a deterministic review artifact for one
`affordance_patch_candidate.json` generated by the LARQL Affordance Patch Probe
scaffold.

## Inputs

- One `affordance_patch_candidate.json`.

The candidate should already contain host affordance context, source files,
source digests, repair lane, probe prompts, and regression prompts.

## Outputs

The helper writes exactly:

```text
dogfood_report.md
dogfood_report.json
```

## Verdicts

The JSON report includes deterministic verdicts:

- `classification_verdict`
- `specificity_verdict`
- `split_host_safety_verdict`
- `provenance_verdict`
- `promotion_verdict`

`promotion_verdict` is always `hold_pending_probe` in v0.

## Why promotion is held

A dogfood report is evidence about candidate shape. It is not probe evidence,
not an applied LARQL patch, not LoRA training data, and not proof that an
affordance overlay is safe. Any promotion remains held pending explicit probes
and operator review.

## Fit with LARQL Affordance Patch Probe v0

Run the probe first to generate the candidate, classification report, and probe
plan. Then run this report scaffold on the candidate to review whether the
generated artifact is specific enough to probe.

## Non-goals

- No LARQL execution.
- No model calls.
- No LoRA training.
- No adapter, checkpoint, model, or vindex artifacts.
- No automatic acceptance or promotion.
- No Git operations.

## Sample command

```bash
python3 local_harness/affordance_dogfood_report.py \
  --candidate .work/larql_affordance_probe/navigator_cuda_real_v3/affordance_patch_candidate.json \
  --out .work/affordance_dogfood_reports/navigator_cuda_v0
```
