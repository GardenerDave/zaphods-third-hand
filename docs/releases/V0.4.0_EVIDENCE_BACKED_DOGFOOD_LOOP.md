# v0.4.0 — Evidence-Backed Dogfood Loop

## Release

v0.4.0 — Evidence-Backed Dogfood Loop

## Summary

This release documents the completed supervised long-duration dogfood loop
that turned repeated review evidence into a declarative, evidence-backed
milestone map and a closeout stop point. The result is a bounded workflow that
keeps recommending work only while evidence is missing, then stops for operator
review instead of repeating completed targets.

## What Changed

- Supervised long-duration cron/tick loop
- Safe-check-gated recommendations
- Queue approval path validator scaffold
- Queue approval path calibration
- Read-only queue approval review command
- Queue approval review command calibration
- Declarative milestone map
- Milestone map calibration
- Long-duration dogfood closeout

## Why It Matters

- The loop exposed stale recommender behavior.
- Repeated symptom patches led to the missing abstraction.
- Declarative evidence-backed milestones replaced nested one-off stale guards.
- The system stops at operator review before selecting another lane.
