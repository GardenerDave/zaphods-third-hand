# ZTH Cross-Agent Agreement Map Template

Use this template during synthesis to make independent convergence reproducible.

```yaml
output_contract_version: zth.agreement_map.v0.2
```

## Cross-Agent Agreement Map

Repeat this block for each agreement or convergence:

### Agreement: <finding or topic>

- Finding/topic:
- Agents that independently found it:
- Role lenses involved:
- Final synthesized severity/priority:
- Confidence:
- Why the convergence matters:
- Evidence basis:
- Human follow-up needed:

## Notes

- Agreement is not automatic truth. It is stronger evidence that still needs human review.
- Convergence across different role lenses is generally stronger than convergence from similar roles.
- Keep disagreement entries separate in `## Disagreements` so conflict remains visible.
