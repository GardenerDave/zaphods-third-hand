# 1.7B Economic-Routing Research Phase Synthesis

Status: research phase closed; review-only evidence, with no production
routing or capability-card authority.

## Research arc

The experiments are separate samples and should not be pooled as one
experiment.

- Early deterministic recovery work demonstrated reusable interventions.
- Run 3 showed that evidence-guided routing could reduce stronger-teacher use.
- Run 4 showed that binary supported-positive evidence was insufficient for
  capability substitution: the cheap deterministic action did not preserve
  triage capability.
- Run 4B showed a fresh replicated scope efficiency pattern: local and
  external teachers both solved the tested scope tasks while local used less
  resource.
- Run 5 showed that static local-for-external substitution could lose a rare
  solve on a fresh mixed portfolio.
- Run 6 showed that validation-gated economic routing could preserve observed
  portfolio quality and reduce cost, but its escalation branch was unobserved.
- Run 7 naturally exercised escalation, failed quality preservation, and
  exposed a recovery-path integration defect.
- Paired-artifact forensics identified lossy escalation teacher-guidance
  integration: semantic guidance collapsed to parse-status-only worker input.
- The integration repair was model-free and separately frozen; Run 7 evidence
  remained historical and unchanged.
- Run 8 exercised the repaired branch on a fresh sample: local-first passed
  18/20, both failures escalated, both were rescued, final treatment solved
  20/20, external-direct control solved 20/20, and audited realized treatment
  policy elapsed was 60.843% lower.

## Resulting architecture

The supported research architecture is:

```text
cheap evidenced supplier
        -> deterministic validation
        -> stronger supplier only on detected failure
        -> deterministic validation
        -> durable evidence
```

Run 8 closes the current 1.7B economic-routing research phase. This means the
validation-gated sequential mechanism has a successful fresh sample result;
it does not establish universal reliability, universal local/external
equivalence, or production routing authority.

The Run 8 raw aggregate remains historically bound to its original hash. Its
review-only sequential-cost correction is documented separately in
`docs/research/RUN_8_SEQUENTIAL_COST_AGGREGATION_ERRATUM_2026-08-20.md`.

## Next phase: model-size supplier floor

Research question:

> What is the smallest model that can take repeatable stewardship of a bounded
> ZTH capability while remaining economically useful under the now-confirmed
> validation-and-escalation architecture?

This treats model size as a supplier cost/capability variable, not as a
generic intelligence benchmark. No model has been selected, no M-parameter
experiment has been preregistered, and no routing authority has changed.
