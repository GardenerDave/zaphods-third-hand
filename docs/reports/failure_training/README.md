# Failure Training Reports

This directory is for curated reports produced by failure curriculum runs.

Typical report artifacts include:

- cycle summaries
- reviewed curriculum summaries
- dataset manifests
- SFT export manifests
- adapter manifests
- before/after evaluation reports
- regression reports

Generated run outputs should usually live under `.work/failure_training/`.

Curated summaries may be copied here when they are useful as project evidence. Raw generated datasets should generally stay out of docs unless they are intentionally tiny fixtures.
